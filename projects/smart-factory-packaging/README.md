# Smart Factory Packaging Alert System

> AI 기반 제품 분류와 작업자 포장 알림을 제공하는 스마트팩토리 팀 프로젝트

## 프로젝트 개요

컨베이어로 이동하는 제품을 카메라로 인식하고 제품 종류와 생산량을 집계한 뒤,
박스 적재가 완료되면 작업자에게 포장이 필요하다는 알림을 제공하는 시스템입니다.
실제 밀봉·포장 장치 대신 제품 분류, 생산 이력, 박스 완료 감지, 작업자 알림,
관리자 모니터링에 초점을 맞췄습니다.

## 프로젝트 정보

| 항목 | 내용 |
|---|---|
| 개발 형태 | 팀 프로젝트 |
| 핵심 기술 | Python, Raspberry Pi, OpenCV, YOLO, MQTT, MySQL |
| 하드웨어 | 컨베이어, 카메라, 센서, 서보모터, LCD, LED, 부저 |
| 담당 역량 | 요구사항 정리, DB 설계, 일정·회의록 관리, 시스템 흐름 정리 |

## 주요 기능

- 작업자·관리자 로그인 및 권한 구분
- 카메라 기반 제품 감지·촬영·분류
- 제품 종류별 생산량 및 세트 수량 집계
- 박스 적재 완료 감지와 서보모터 기반 박스 배출
- LCD·LED·부저를 이용한 작업자 포장 알림
- 생산 세션, 제품, 시스템 구성요소, 알림 이력 관리

## 시스템 흐름

```text
작업자 로그인
    ↓
생산 세션 시작
    ↓
카메라 촬영 → AI 제품 분류
    ↓
제품·생산량 DB 저장
    ↓
박스 적재 완료 판단
    ↓
서보모터 배출 + LCD·LED·부저 알림
    ↓
관리자 화면에서 생산 현황·오류 이력 확인
```

## 대표 트러블슈팅

### 1. 프로젝트 범위 과대

**문제**  
자동 밀봉·포장까지 포함하면 구현 범위가 지나치게 커짐

**해결**  
실제 포장 기능을 제외하고 ‘자동 분류 및 작업자 포장 알림 시스템’으로 범위를 재정의

### 2. 작업자 추적 구조

**문제**  
PRODUCTS에 user_id를 직접 두면 생산 세션과 사용자 정보가 중복됨

**해결**  
PRODUCTS는 session_id와 연결하고 PRODUCTION_SESSIONS를 통해 작업자를 추적하도록 ERD 수정

### 3. 알림 원인 추적

**문제**  
오류 발생 시 어떤 작업·제품·장비에서 발생했는지 구분이 어려움

**해결**  
ALERTS를 세션·제품·시스템 구성요소와 연결해 발생 원인을 추적하도록 설계

## 프로젝트 결과
