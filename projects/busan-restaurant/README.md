# Busan Restaurant Data Service

> 부산 음식점 공공데이터 기반 검색·조회 프로젝트

## 프로젝트 개요

부산 지역 음식점 공공데이터를 수집해 상호명, 주소,
업종 등의 정보를 조회하고 조건에 따라 검색할 수 있도록 구성한 프로젝트입니다.

## 프로젝트 정보

| 항목 | 내용 |
|---|---|
| 핵심 기술 | Python, OpenAPI, JSON |
| 주요 기능 | 음식점 정보 조회와 조건 검색 |
| 데이터 | 부산 지역 음식점 공공데이터 |
| 형태 | 학습·미니 프로젝트 |

## 주요 기능

- 음식점 OpenAPI 데이터 수집
- 상호명·지역·업종 기준 검색
- 필요 필드 추출과 출력 형식 정리
- 빈 값과 잘못된 응답 예외 처리

## 시스템 흐름

```text
Restaurant OpenAPI
    ↓
JSON Data
    ↓
Parsing / Normalization
    ↓
Keyword and Region Filter
    ↓
Search Result
```

## 대표 트러블슈팅

### 1. 필드명 불일치

**문제**  
문서의 항목명과 실제 응답 키가 달라 값이 출력되지 않음

**해결**  
실제 응답 JSON을 기준으로 필드 매핑 수정

### 2. 검색 결과 없음

**문제**  
공백·대소문자·지역 표기 차이로 검색 누락

**해결**  
문자열 정규화 후 포함 검색 적용

## 프로젝트 결과

- 공공데이터 기반 검색 기능 구현
- 데이터 구조 확인과 필드 매핑 능력 향상
- 사용자 조회 목적에 맞춘 결과 정리
