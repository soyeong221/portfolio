# Busan Tourism Data Service

> 부산 관광 데이터를 조회·가공하는 데이터 활용 프로젝트

## 프로젝트 개요

공공 OpenAPI에서 부산 관광 정보를 수집하고,
필요한 항목을 가공해 사용자가 관광지 정보를 조회할 수 있도록 구성한 데이터 활용 프로젝트입니다.

## 프로젝트 정보

| 항목 | 내용 |
|---|---|
| 핵심 기술 | Python, OpenAPI, JSON, Data Processing |
| 주요 목적 | 관광지 정보 수집과 사용자 조회 |
| 데이터 | 부산 지역 관광 정보 |
| 형태 | 학습·미니 프로젝트 |

## 주요 기능

- OpenAPI 요청과 JSON 응답 처리
- 관광지 이름·주소·설명 등 주요 정보 추출
- 조건별 관광 정보 조회
- 데이터 누락과 오류 응답 처리

## 시스템 흐름

```text
Busan Tourism OpenAPI
    ↓ HTTP Request
JSON Response
    ↓
Python Parsing / Filtering
    ↓
Tourism Information Output
```

## 대표 트러블슈팅

### 1. 응답 구조 차이

**문제**  
API 응답 단계와 실제 데이터 배열 위치를 잘못 참조

**해결**  
원본 JSON 구조를 확인하고 필요한 키 경로를 단계별로 분리

### 2. 누락 데이터

**문제**  
일부 관광지의 설명·이미지·주소가 비어 있음

**해결**  
`get()`과 기본값을 적용해 출력 오류 방지
