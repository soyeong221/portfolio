## About Me

전기·반도체 전공을 기반으로 IoT 시스템 개발 과정을 수료하며  
센서 데이터 수집, 장치 제어, 네트워크 통신, 데이터베이스, 모니터링 시스템을 학습했습니다.

기능 구현뿐 아니라 요구사항, 시스템 흐름, DB 구조, 오류 원인과 해결 과정을 문서화하며  
프로젝트를 구조적으로 이해하고 정리하는 역량을 쌓았습니다.
